# K3 实施报告：人物传记引用来源

日期：2026-11-11  
结论：**已实现传记的文档级来源追溯**；未实现逐句引用/自动事实校验。

---

## 1. 数据层

`character_biographies` 新增 `citations` JSON（M026）：

```json
[
  {"kind": "event", "id": "...", "title": "事件名", "story_time": "..."},
  {"kind": "life", "id": "life:1", "title": "生平经历", "story_time": "..."},
  {"kind": "growth", "id": "growth:1", "title": "成长校准", "story_time": "..."},
  {"kind": "diary", "id": "...", "title": "日记", "story_time": "日期", "source_type": "user"}
]
```

无新表，63 表不变。

## 2. 来源生成

- 事件：只取传记聚合中实际参与的事件，不含无关事件；
- 生平/成长：按履历与成长日志顺序编号；
- 日记：取 `character_id` 指向该人物的日记，带来源类型；
- AI 生成与手动保存都会把当时的 citations 固化到传记行；
- 后续新增事件不会改写旧传记的来源列表。

## 3. 前端

- 传记弹窗「自传」页底部新增「引用来源 · N 项」；
- 分类展示事件/生平/成长/日记，含标题与时间；
- 明示"文档级溯源，不表示逐句引用"；
- 没有来源时不显示该区块；
- 人物列表入口不变。

## 4. 实测

- `smoke_biography_citations.py`：**7 项通过**（参与事件、排除无关事件、日记、手动保存、固化、最新版保留）；
- 全量：**400 passed / 0 failed / 16 suites**；
- 迁移演练：26/26，63 表；
- 浏览器：官方人物南宫婉传记 →「自传」显示"引用来源 · 2 项"（世界事件/生平经历）；
- `tsc`、`vite build` 通过。

## 5. 未做 / 边界

- 无逐句脚注（AI 文本不强制内嵌 `[n]`，避免伪造精确引用）；
- 无来源事实一致性校验、无冲突提示；
- 未把故事线人物线/聊天记录纳入传记来源（聊天可先转日记，再以日记进入来源）；
- 未做传记版本对比/来源差异。

## 6. 兼容性

- 旧传记 `citations` 迁移回填空数组，页面不显示来源区块；
- 传记 API 新增字段，旧客户端忽略即可；
