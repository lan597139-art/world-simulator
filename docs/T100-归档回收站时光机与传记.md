# T100 归档、回收站、时光机、人物传记与官方演示世界

## 1. 人物传记与履历

入口：人物管理卡片 →「传记」。

- 后端聚合 `life_history`、人物参与的事件、`EventEntity`、推演行动、成长日志、关系与相关章节。
- 「生平履历」按时间排序展示事件、行动、结果与影响。
- 「一键生成自传」优先调用当前请求的 AI Key（访客 Key 或站长 Key），生成第一人称自传。
- AI 不可用或失败时自动回退为本地生平整理版，不会让按钮失效。
- 自传存入 `character_biographies`，支持手动编辑后再保存。

API：

- `GET /api/characters/{id}/biography`
- `POST /api/characters/{id}/biography/generate`
- `POST /api/characters/{id}/biography`

## 2. 全局归档

入口：侧栏「数据安全 → 归档库」。

- 世界、人物、章节支持 `archived_at` 封存。
- 归档不是删除；数据、关系、章节正文全部保留。
- 归档人物不出现在人物列表，也不参与推演。
- 归档世界不出现在世界书架，不能继续推演。
- 归档章节不出现在章节列表。
- 官方演示世界锁定，禁止归档和删除。

API：

- `GET /api/archive`
- `POST /api/archive/{type}/{id}`
- `POST /api/archive/{type}/{id}/restore`

## 3. 全局回收站

入口：侧栏「数据安全 → 回收站」。

- 删除人物、世界、章节、地点、事件、组织、关系时不再直接丢失。
- 非世界对象：删除前保存整行 JSON 快照与目录节点，恢复时按原 ID 重建。
- 世界对象：软删除整个 `World`，世界内数据全部保留；恢复只需清除删除标记。
- 章节回收站额外保存本章草稿，恢复时一并回来。
- 回收站支持单条恢复、彻底丢弃、清空。

API：

- `GET /api/trash`
- `POST /api/trash/{id}/restore`
- `DELETE /api/trash/{id}`
- `DELETE /api/trash`

## 4. 时光机

入口：进入世界后 → 侧栏「数据安全 → 时光机」。

- 快照覆盖所有带 `world_id` 的业务表：人物、事件、地点、组织、关系、章节、推演、草稿、世界结构、制度、资源、历史记录等。
- 额外保存 `rule_scopes` 与全局地点/资源/关系类型。
- 回滚在事务中清空当前世界业务数据，再按依赖顺序重建；世界 ID 保持不变。
- 快照本身不会在回滚中被删除，回滚前可以再打一针“后悔药”。

API：

- `GET /api/worlds/{id}/snapshots`
- `POST /api/worlds/{id}/snapshots`
- `POST /api/worlds/{id}/snapshots/{snapshot_id}/restore`
- `DELETE /api/worlds/{id}/snapshots/{snapshot_id}`

## 5. 官方防删演示世界

- 首次启动自动内置《凡人修仙传》，数据来自 `backend/seed/fanren.json`。
- 世界标记 `is_official=true`、`official_key=fanren`。
- 删除接口返回 409，前端隐藏删除按钮并显示「官方演示 · 锁定」。
- 世界卡片提供「重置演示」：恢复内置初始人物、事件、关系、章节、世界结构；其他世界不受影响。
- 已存在同名《凡人修仙传》时只标记为官方，不覆盖当前数据。

API：

- `POST /api/worlds/{id}/reset-official`
