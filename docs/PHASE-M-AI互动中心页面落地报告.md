## 页面设计

- Hero：标题、说明、角色 / 会话 / 记忆 / 关系四项真实统计与「开始对话」。
- 推荐角色：3 位真实人物，按 AI 伴侣、主角、重要配角、配角、反派排序。
- AI 伴侣：深色 Bento，展示伴侣角色、真实会话与记忆、AI 人格数；提供人格中心、记忆、云宝入口。
- 最近会话：真实聊天线程，展示参与角色、最后消息、消息数、日期；只展示有消息的线程。
- 多人聊天室：真实群聊线程与参与角色。
- 我的角色：6 位真实角色名册，搜索 + 六类筛选 + 结果计数。
- 关系互动：真实关系记录与互动事件统计、3 条人物关系样本。
- 记忆管理：真实长期记忆总数与 3 条样本。
- 角色与玩法：角色扮演、创建角色、发布/授权边界说明。

## 实际交互

- 「开始对话」进入伴侣角色真实聊天，并自动带入对应产品与世界。
- 角色卡「对话」、名册卡、最近会话、群聊「进入聊天室」均进入现有聊天页。
- 分类筛选「反派」实时收敛为墨居仁 1 位；搜索覆盖姓名、角色、身份、简介与世界。
- 「关系网络」进入 `?product=game&world=凡人修仙传&page=relationships`。
- 「互动事件」进入真实事件页。
- 「管理记忆」进入伴侣记忆管理；「AI 人格中心」进入人格管理；「打开云宝」打开全局云宝。
- 「进入模拟」「创建角色」进入真实模拟与人物管理。
- 发布与授权显示 0/0 真实空状态，不提供假提交。

## 边界

- 单用户本地空间，没有公开角色广场、关注或跨用户授权。
- 角色发布、公开授权、使用范围与收益没有后端；本轮明确显示空状态，不伪造发布结果。
- 只展示有消息的真实会话；空线程不进入「最近会话」。
- 未修改后端、数据库、API；无新增表。
