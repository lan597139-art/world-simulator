## 2. 故事线：真实树状图

### 2.1 数据

新增 `StoryTreeNode`（`story_tree_nodes`）：

- `thread_id`：所属树干/树枝（复用既有 `StoryThread`）。
- `parent_node_id`：事件叶下再分叉的层级。
- `event_id`：引用既有 05 事件，可为空；为空即待填充位置。
- `node_status`：`filled / pending / new`。
- `order_index / collapsed / note`。

节点只保存引用，不复制事件正文。既有 `story_thread_events`、`story_thread_edges` 和相关 API 保留；旧人物线有事件链接但无树节点时，`GET /api/stories/{id}/tree` 会一次性补齐树节点。

### 2.2 接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/stories/{id}/tree` | 返回树枝、树节点、事件叶、连线与统计；必要时从旧人物线引导 |
| POST | `/api/stories/{id}/tree/nodes` | 在指定树枝创建事件叶或待填充位置 |
| PATCH | `/api/story-tree-nodes/{id}` | 填事件、改标题/备注、移动树枝、改父节点、排序、折叠 |
| DELETE | `/api/story-tree-nodes/{id}` | 移除节点；不删除 05 原始事件 |
| POST | `/api/stories/{id}/tree/bootstrap` | 显式补齐旧人物线 |

树枝本身继续复用 `StoryThread` 的创建/编辑/删除 API：名称、类型（主线/人物支线/副本/暗线/群像）、归属人物、上级树枝、同级排序均可改；父子成环会被拒绝。

### 2.3 页面

`StoryTreePage` 替换原三栏技术配置页：

- 树干是 `kind=main` 的根树枝；其他树枝通过带转折线的缩进层级挂在树干或彼此之下。
- 事件叶为实线卡片；待填充位置为琥珀色虚线卡片；每个树枝底部有「＋待填充位置」。
- 05 事件库可搜索、可拖拽；拖到树枝空白处追加事件叶，拖到待填充位置直接填入。
- 点击待填充位置后，再点右侧事件也可填入；节点标题/备注可后续编辑。
- 每个树枝可展开/收起、新增子枝、编辑名称/类型/归属/上级/排序。
- 删除树枝或节点只删树结构，不删 05 事件；已有数据与旧连线保留。

## 3. 六轴压强：具象对象统一配置

### 3.1 数据语义

新增 `AxisObject`（`axis_objects`）：

| 字段 | 说明 |
| --- | --- |
| `axis` | 稀缺/威胁/地位/声誉/依恋/调节/负熵 |
| `name / category / description` | 具体对象，如“缺钱”“身份暴露”“师徒关系” |
| `value` | 0–1；六轴越高压力越大，负熵越高修复力越强 |
| `scope_type / scope_id` | world / event / branch |
| `event_id / branch_id` | 便于按作用域查询 |
| `linked_factors` | 人物/事件/关系/资源/环境/组织等关联 |
| `source` | initial / event / user / simulation |

负熵独立成维度，并在 UI 中与六轴压力分区解释，不混成一个“总压力”。

### 3.2 多对象、继承与覆盖

- 同一维度允许多个对象，各自独立数值；不会先合并成一个抽象值。
- 生效顺序：世界基础 → 事件层 → 分支层；同 `axis + name` 后层覆盖前层，其他对象继续保留。
- 事件/分支层可以新增对象，也可以对继承对象点「在此覆盖」建同名对象；删除覆盖后自动回退世界值。
- 预设不设上限：七维各有大量可选对象，且始终支持完全自定义名称/分类/描述/数值。
- 接口汇总均值只用于展示；原始对象列表仍是唯一配置源。

### 3.3 接口与页面

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/axis-objects/presets` | 七维预设清单 |
| GET | `/api/worlds/{id}/axis-objects?event_id=&branch_id=` | 当前作用域对象、生效集合、均值 |
| POST | `/api/worlds/{id}/axis-objects` | 新增世界/事件/分支对象 |
| PATCH | `/api/axis-objects/{id}` | 改对象名称/描述/数值/关联 |
| DELETE | `/api/axis-objects/{id}` | 删除对象 |

`AxisObjectsPanel` 已接入：

- 世界建设页：世界基础配置。
- 05 事件详情/沙盒：当前事件继承/覆盖，以及已创建分支的继承/覆盖。
- 07 / 多路径工作台：分支沙盒调用，替代旧的抽象六轴滑杆。
- 全局 AI：世界上下文读取生效对象与均值。
- AI 角色聊天影响：有具象对象时，对话增量同步落到对象值，不再只写旧 `settings.six_axis`。

分支推演还会把当前生效对象与 05 沙盒方案一起送入推演提示词。

## 4. 03 人物管理：个人 AI 人格

### 4.1 数据

| 表 | 作用 |
| --- | --- |
| `personal_personas` | 名称、身份、描述、ESA、特征、认知、表达、互动、记忆策略、公共资料、工具、状态 |
| `persona_threads` | 每个人格独立会话 |
| `persona_messages` | 会话消息 |
| `persona_memories` | 每个人格独立记忆 |

人格不是世界 NPC；所有会话/记忆查询强制带 `persona_id`，不存在跨人格混用。

### 4.2 功能

- 03 人物管理新增「个人 AI 人格」入口。
- 可从“理性严谨的我 / 安静内向的我 / 自由松弛的我”模板创建，也可自定义。
- 可编辑 ESA 五维动力、特征标签、认知倾向、表达语气、互动关系。
- 独立会话列表、新会话、删除会话、聊天历史；每人格各自一套。
- 独立记忆列表、写入、删除、重要度。
- 公共资料必须显式勾选授权；未授权时提示词明确不引用，授权后才把昵称/简介/偏好送入人格提示词。
- 全局 AI 助手头部增加人格选择：默认“通用助手（页面上下文/工具）”，也可选任一个人格；选人格后走独立会话与记忆。
- 人格对话复用全局 `ai_engine` 的模型/Key/Base URL 配置，不新建第二套 AI 栈。
- 支持日常聊天、情感互动、知识问答、信息整理和任务协助；工具能力以人格配置与全局模型能力为准。

### 4.3 接口

`GET/POST /api/personas`、`PATCH/DELETE /api/personas/{id}`；  
`GET/POST /api/personas/{id}/threads`、`GET/DELETE .../threads/{thread_id}`、`GET .../messages`；  
`GET/POST /api/personas/{id}/memories`、`DELETE .../memories/{id}`；  
`POST /api/personas/{id}/chat`。

## 5. 05 事件：分支沙盒入口与方案

### 5.1 正确流程

05 事件库中选一个已保存事件 → 点「事件详情 · 分支沙盒」→ 在弹窗中看事件详情并配置方案。创建事件时不再要求配置沙盒；顶部旧的通用“分支沙盒”入口已移除。

### 5.2 数据

新增 `EventSandboxScenario`（`event_sandbox_scenarios`）：

- `event_id`：只关联既有事件，不复制、不覆盖。
- `title / note`：方案名与备注。
- `preset_options`：A 预设选项。
- `constraints`：B 约束条件。
- `supports`：C 支持条件。
- `potentials`：D 潜在条件，默认 `status=potential`，不会被自动写成事实。
- `factors`：E 可能关联（人物/组织/资源/环境/事件/关系）。
- `branch_id`：关联实际创建的 `SimulationBranch`。

### 5.3 方案操作

- 同一事件可建多个独立方案，每个方案分别保存。
- A–E 每项都支持从系统候选添加、自定义添加、页内编辑、删除。
- 多方案勾选后比较：预设数量、约束、支持、潜在、关联、分支状态。
- 「创建真实分支沙盒」复用 `POST /api/branches`，然后把分支 ID 写回方案；原事件不动。
- 分支创建后可直接跳 07 模拟运行或 08 写作辅助选择该分支。
- 真实分支推演时，方案 A–E 会进入推演上下文；D 潜在条件明确以“未确认候选”传入，不自动成为事实。

### 5.4 07 / 08 选用

- 07 模拟运行选择事件后，多路径区域列出该事件的真实分支，可逐个“在分支中推演”；官方演示两条分支已显示。
- 08 写作辅助的“素材/生成”弹窗中，启用多路径创作后可选择任一分支；选择后只取该分支素材。
