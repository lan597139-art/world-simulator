## 三、自动化验收覆盖

### 1. 世界与目录（T065–T067）

- 创建世界、读取世界、删除世界后返回 404。
- 新世界自动生成 8 个一级分支节点。
- 目录节点支持 `entity_ref`，可绑定/解绑地点、组织；非法引用类型返回 422。
- 有子节点的目录节点禁止直接删除（409）。

### 2. 地理结构（T068–T069）

- 按类型白名单建立 世界 → 国家 → 省 → 市 → 城区 层级。
- 非法父子类型返回 409；移动形成环返回 409。
- 地点移动写入 `state_histories`（`parent_location_id`）。
- 有子地点的地点禁止删除（409）；跨世界父节点返回 409。

### 3. 组织架构（T070–T072）

- 组织、部门、职位创建成功；组织树返回部门数量与层级。
- **本次新增验收**：
  - 组织改名与状态变更（`PATCH /organizations/{id}`）。
  - 部门改名与部门移动（`PATCH /organization-units/{id}`）。
  - 部门移动到自己的下级返回 409（环检测）。
  - 职位改名与职级修改（`PATCH /organization-positions/{id}`）。
  - 任职支持指定 `start_time`；离任支持指定 `end_time`，状态置为 ended。
  - 有任职历史（含已离任）的职位禁止删除（409，保护历史）。

### 4. 统一关系模型（T082–T084）

- 关系创建、端点类型校验、跨世界校验。
- 关系类型配置 ≥ 40 条；非法端点组合（人物→人物使用“总部位于”）返回 409。
- 关系状态变更写入历史；`/relationships/{id}/history` 可读取 ≥ 2 条。
- **本次新增验收**：
  - 关系可写 `valid_from` / `valid_until`（ISO 字符串正确落库）。
  - 结束关系为软删除：状态 ended、保留记录、历史可查。
  - 已结束关系不能直接恢复为 active（409）。
  - 单向关系不会自动生成反向记录。
  - 组织 → 资源关系（`持有`）创建成功，资源时间线可读。

### 5. 事件与因果（T089–T091）

- 事件创建，`events/{id}/entities` 自动同步 2 条关联。
- 参与方（发起者/决策者）与影响对象（损失/高）分别读写。
- 事件因果：causes 创建成功；重复因果 409；自环 422。
- 人物认知：写入、读取、覆盖更新（同一人物同一事件仅 1 条）、删除。
- **本次新增验收**：认知覆盖更新与删除后列表为空。

### 6. 状态历史与时间线（T092–T095）

- 地点移动、关系变更、任职变化均写入 `state_histories`。
- 世界时间线：事件 ≥ 2、历史变化 ≥ 1。
- **本次新增验收**：人物 / 组织 / 地点 / 资源四个 scope 的时间线接口均可读取。

### 7. 规则、资源、时空（T074–T077）

- 规则适用范围内查询命中 1 条。
- 资源持有区分 holder / manager / user；交易后数量 100 → 80。
- 世界时间手动推进与实时模式切换成功。

### 8. 界面闭环（T085–T095）

- 关系图节点覆盖人物、组织、地点、资源四类；资源关系类型（持有/管理/使用/分配等）已在配置中。
- 点击人物节点跳转人物管理并直接打开该人物档案；点击组织/地点节点进入结构/数据页面。
- 时间线条目可点击：历史与资源流水显示来源事件；事件条目显示因果链（入边/出边、关系类型、置信度）。

### 9. 引用完整性（T078）

- 删除被目录节点、关系、事件、任职历史引用的实体均返回 409，并提示引用来源。
- 跨世界关联（关系、地点父节点）返回 409。
- 删除世界级联清理成功。

## 四、本次验收中发现并修复的问题

| 问题 | 现象 | 修复 |
|---|---|---|
| 时间字符串直接写入 DateTime 列 | 指定任职开始/结束时间、关系有效期时返回 500 | 新增 `common.parse_datetime`，在任职、关系、认知、资源、时代接口统一转换 |
| 有历史任职的职位删除 | 引用检查只查“在任”，删除时触发外键错误返回 500 | `reference_guard` 改为统计全部任职记录（含历史），返回 409 并说明“删除会破坏历史” |
| 人物/组织删除只查在任记录 | 存在已离任记录时可能 500 | 同上，改为统计全部任职历史 |
| 关系变迁史使用系统时间 | 关系创建/变更/结束写入 2026 年，插在世界时间线最前 | 新增 `common.world_now`；关系历史默认取世界当前时间，并支持 `occurred_at` 显式指定 |
| 人物/组织时间线缺关系变化 | 韩立时间线只有任职记录，看不到师生/控制变迁 | 时间线按实体端点并入关系历史，并把 `appointment` 标题解析为“人物 — 职位（任职）” |
| 社会实体成立时间报 500 | `founded_at` 字符串直接写入 DateTime 列 | `society.py` 创建/更新统一使用 `parse_datetime` |
| 目录节点无法绑定社会/时代 | 世界基础里绑定时代、人物与群体里绑定社会实体返回 422 | `common.ENTITY_MODELS` 增加 `society`、`era`，节点、规则等引用解析同步支持 |
| 前端 TypeScript 配置 | TS7 移除 `baseUrl`，`tsc` 无法运行 | 删除 `tsconfig.app.json` 的 `baseUrl`，保留 `paths`；清理 4 处未使用变量 |
