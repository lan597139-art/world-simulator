## 页面设计

- Hero：标题、说明、真实内容统计与「发布作品」入口。
- 发布面板：标题、关联世界、正文、发布/草稿切换，调用现有写作 API 写入真实创作库。
- 工具栏：搜索、五个分类筛选、结果计数与清除。
- 推荐区：1 篇主推荐 + 2 篇作品，来自当前真实作品库。
- 世界 / OC：左右 Bento，世界含简介和核心设定，OC 3×2 展示。
- 剧情 / 创作动态：左右 Bento。
- 创作者 / 关注：创作者档案与真实作品；关注 0/0 空状态。
- 热门 / 共创：真实等待状态，不生成假榜单或假项目。

## 真实数据

截图时本地库：

- 作品 3 篇；推荐主作品 `推演 · 韩立通过黄枫谷入门测试`，正文 1176 字符、997 字。
- 世界 1 个：`凡人修仙传`。
- OC 6 位；展示姓名、身份、简介。
- 剧情项目 1 个：`凡人修仙传 · 七玄门篇`。
- 关注 0 / 粉丝 0；热门榜单 0；共创项目 0。

搜索「韩立」返回 7 条：2 篇作品、1 个世界、4 位人物。筛选「作品」返回 3 条。

## 实际交互

- 搜索与分类筛选为真实客户端检索，覆盖标题、正文、简介、设定与剧情 premise。
- 点击作品打开阅读器，读取真实 `plain_text`；空正文显示真实空状态。
- 分享调用剪贴板；失败时显示可手动复制的社区链接面板，不制造“已复制”假反馈。
- 发布作品：调用现有 `POST /api/writings` 真实创建；成功后插入推荐/动态，标题必填，发布需正文，草稿可空正文。
- 阅读器“在写作页打开”：进入完整写作工作台；无当前世界时自动进入首个真实世界。
- 世界入口 → 世界管理；OC → 人物管理；剧情 → 故事线管理；创作者 → 身份中心。
- 创作动态按真实 `updated_at` 排序。

## 边界

- 当前只有单用户本地创作库，没有公开用户、帖子、评论或关注关系。
- 点赞、评论、收藏、关注、共创没有后端支持；本轮明确显示真实空状态，不伪造互动数量。
- 热门榜单需要真实互动数据，当前不生成排名。
- 没有作品版本表；页面只展示真实状态、创作方式与最近更新时间。
- 「发布作品」复用现有写作 API 写入本地创作库，没有新增社区投稿、审核或公开分发后端。
