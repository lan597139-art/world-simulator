# 阶段四·内容社区与体验中心合并改造 —— 现状审计与验收

> 所属任务书：《世界模拟器｜DSH 后续架构升级任务书（完整版）》· 内容社区与体验中心合并改造
> 审计范围：**仅本次合并涉及的内容社区 / 体验中心 / 作品体验 / 社区互动**，未扩大到其余主线
> 执行方式：先核对现有实现再确定最小修改范围；完成一条、验收一条
> 硬约束：不得破坏现有发布 / 浏览 / OC 体验；**不得未经用户确认扣除灵果**；**不得自行确定体验定价与创作者收益规则**；AI 调用不设计为灵果消费

---

## 1. 任务目标

1. 将体验中心合并进内容社区，**删除独立体验中心产品入口**，内容社区成为唯一作品发现与体验入口。
2. 用户通过内容社区发现作品（世界 / OC / 小说 / 故事线 / 公开作品），进入统一作品详情页，自主选择**普通体验**或**灵果体验**。
3. 作品详情页区分两种体验模式；普通体验不消耗灵果，灵果体验在用户确认后由服务端校验并扣减。
4. 完善作者内容权限（普通公开 / 灵果体验内容 / 访问范围 / 作者归属校验）。
5. 灵果业务闭环：扣除入口、服务端余额校验与扣除、体验权限发放、重复点击防护、体验记录与流水、作者归属。
6. 保留并打通社区互动：**评论、点赞、分享、收藏、推荐、打赏**，覆盖世界 / OC / 小说 / 故事线。
7. 删除游戏体验中心及相关功能，不重复开发、不破坏既有能力。

## 4. 关键业务规则（服务端强制）

### 4.1 体验模式

| 模式 | 是否消耗灵果 | 可见内容 | 触发 |
| --- | --- | --- | --- |
| 普通体验 | **否** | 作者允许公开的内容（`public_visible` 门控） | 进入详情即可 |
| 灵果体验 | **是** | 作者设置的 `experience_snapshot` 深度内容 | 用户点击「确认灵果体验」后，服务端校验并扣减 |

- 未开启 / 未配置定价时：详情页只展示说明，**不出现确认扣费按钮，不虚构价格**。
- 灵果体验接口要求 `confirm === true`，**未确认不扣费**。

### 4.2 作者内容权限

- 作者可设置：普通公开内容开关、灵果体验开关、灵果消耗数量、深度体验内容。
- 消耗数量留空时不开放收费体验；**定价与创作者收益规则保留待产品确认，前端不预填、不虚构**。
- 作者归属由 `owner_user_id` 校验；普通用户无权修改他人作品权限。

### 4.3 灵果业务闭环

1. 扣除入口：详情页「确认灵果体验」按钮。
2. 服务端校验：余额、作者权限、业务状态（已发布 / 已开启 / 已定价 / 有内容）。
3. 扣除与发放：扣 `fruit_balance`，写 `SpiritTransaction(kind=experience)`，发放 `CommunityExperienceGrant`。
4. 防重复：`SpiritOperation` 幂等键 + `CommunityExperienceGrant` 唯一约束；重复确认不再扣费。
5. 记录与流水：`SpiritTransaction` 记录 `ref_type=publication / ref_id`，与打赏分别记账。

### 4.4 社区互动

| 互动 | 覆盖 | 防重复 / 校验 | 记账 |
| --- | --- | --- | --- |
| 评论 | 公开作品 | 服务端保存，详情实时展示 | — |
| 点赞 | 公开作品 | `CommunityLike` 唯一约束，重复点赞幂等 | — |
| 分享 | 全部内容 | 复制社区链接 | — |
| 收藏 | 公开作品 | 服务端保存，状态回显 | — |
| 推荐 | 内容社区 | 我的写作库 / 公开作品推荐 | — |
| 打赏 | 公开作品 | 服务端校验余额并扣除，展示数量并确认 | 独立 `tip` 流水，与体验扣费分开 |
