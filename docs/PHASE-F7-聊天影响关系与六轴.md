# 阶段 F7：聊天影响关系与六轴（已实现）

按"允许副作用"落地，但坚持**两段式**：AI 只生成建议，用户预览并确认后才写世界。

---

## 1. 数据层（54 → 55 表）

`chat_impacts`：每条建议保存原始提案、应用结果、状态（pending/applied/dismissed）、模型。
`M018_chat_impact` 只补索引；聊天影响表不进入世界快照，删世界时显式清理。

## 2. 预览（POST /api/chat/threads/{id}/impact/preview）

- 至少一轮对话；取最近 20 条；
- 给模型：参与者 ID/称呼、彼此现有关系、对话记录；
- 要求只输出 JSON：一句话总结 + ≤4 条关系变化 + 六轴增量 + negentropy；
- 服务端校验：
  - 关系只能发生在会话参与者之间，禁止自指、重复；
  - 象限仅允许 漠视/友善/信任/戒备/敌对/竞争/依赖；
  - 强度 弱/中/强，权力 对等/上风/下风；
  - 六轴与 negentropy 增量硬限制在 **-0.1 ~ +0.1**；
  - JSON 非法直接 502，不落库。
- 私聊只有一个角色 → 关系必然为空，只可能产生六轴建议。

## 3. 应用（POST /api/chat/impact/{id}/apply）

- 仅 `pending` 可应用，重复应用 409；
- 关系：按有向 `source→target` 查找既有关系；存在则更新象限/强度/权力并追加描述；不存在则新建「对话影响」；
- 六轴：按增量叠加并 clamp 到 0–1；negentropy 同理；
- 结果写入 `applied`（关系 ID 列表、最终六轴值），状态改 `applied`；
- `dismiss` 只改状态，不动世界。

## 4. 页面

- 有消息的会话显示「影响预览」；
- 面板展示总结、关系建议（双方名字/象限/理由）、六轴增量；
- 按钮「应用影响 / 忽略」，应用后显示状态；日志提示关系条数。

## 5. 实测

- `smoke_chat.py`：**55 项全通过**，新增 9 项：预览关系、增量限制、应用建关系、六轴叠加、状态 applied、重复应用 409、忽略、忽略后不可应用、私聊无关系。
- 真实 AI 端到端（临时世界，已清理）：对话"墨居仁在药园深处转"→ 建议 `threat +0.05`、总结"甲提醒用户保持警惕"；应用后世界 `six_axis.threat=0.05`，审计状态 `applied`。
- 全量回归：**336 passed / 0 failed**；`tsc`、`vite build` 通过。

## 6. 边界

- 只调整会话内角色之间的**有向**关系；不反向写 target 象限。
- 不自动应用，不自动改运行态/六轴以外的世界字段。
- 单次增量上限 ±0.1，关系最多 4 条，避免一次聊天改写世界。
- 关系描述追加而非覆盖；旧描述保留。
- 聊天影响不进入故事线/推演分支，只作用于主时间线世界设定。
