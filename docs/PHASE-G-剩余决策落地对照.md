## 本轮具体改动

1. **G9**：`create_unit` 计算父链深度，父单元已到 4 层则拒绝创建第 5 层（422 `UNIT_DEPTH_EXCEEDED`）。
2. **G13**：私聊/群聊 system prompt 的引擎行从 `V（80/100）` 改为 `生存：强`，数值仍保留在 persona JSON 与配置面板，不进提示词。
3. **G22**：转事件支持 `message_count`（1–100），页面新增条数输入；后端硬截断。
4. **G29**：`tests/run_all.sh` 逐套件执行、汇总总数，任一失败退出。

## 实测

- `backend/tests/run_all.sh`：**353 passed / 0 failed / 10 suites**。
- 新增断言：四层单元可建、第五层被拒；提示词无 `/100` 且含「引擎 生存：强」。
- `tsc`、`vite build` 通过。
