## 2. 边界

- 既有 9 个事件与人物数据未改写；新事件全部带 `branch_id`，只属于出逃线。
- 正史空间只能挂主时间线事件；出逃线中「图谋夺舍」以 `is_shared=true` 标记为共享正史事件。
- 出逃线状态隔离由分支快照承载；不与正史互相污染。
- 导入幂等：`official_key` 唯一；重复启动/重置不会重复创建。
- 重置官方世界后会自动重建故事线（`reset-official` 已接线）。

## 3. 选择节点语义修正

原实现只允许一个选择节点生成一个空间（一次 resolve 即锁定）。为支持「同一选择产生多个平行空间」：

- 每个选项可分别 resolve 并生成自己的空间；
- 只有全部已确认选项都指向空间时，选择节点才自动标记 `resolved`；
- 已生成空间的选项再次 resolve 返回 409，避免重复建分支。
