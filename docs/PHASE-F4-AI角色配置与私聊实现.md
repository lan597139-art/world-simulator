按 `PHASE-E-AI角色聊天室设计.md` 落地第一段：**角色配置 + 私聊 + 记忆**。群聊调度留给 F5，但会话/参与者/计划表已就位。

## 1. 数据层（48 → 54 表）

| 表 | 用途 |
| --- | --- |
| `ai_roles` | 人物在聊天中的运行配置（与 `characters` 分离，不回写档案） |
| `chat_threads` | 私聊/群聊会话 |
| `chat_participants` | 会话成员与发言策略 |
| `chat_messages` | 用户/角色/系统消息 |
| `character_memories` | 角色记忆（按角色 + 会话隔离） |
| `chat_plans` | 群聊发言计划（F5 使用，带审计） |

- `M017_chat` 只补索引；新表由 `create_all` 建出。
- 聊天表**不进入世界快照**；删世界/重置时按会话依赖顺序显式清理。
- 角色配置不写入 `characters`，避免聊天行为污染正式档案。

## 2. 档案 → 角色配置（确定性转换）

不调用 AI 生成人设，避免编造。输入既有字段：

- `basic_profile` → 身份、职业、年龄、性别、背景；
- `engines.ovtde`（嵌套或扁平）→ V/O/D/E/T 数值、行为描述；支持 `"O 秩序"` 这类键；
- `engines.dominance` → 主导模式、涉及引擎、运行描述；
- `defense_mechanisms` → 防御机制文本；
- `thought_imprints` → 思想印记；
- `life_history` → 重要经历；
- `reality_conditions` → 现实条件；
- `relationships` 若存在 → 对用户的初始态度。

默认只补**中性表达约束**（语气"贴合身份与处境"、不替用户行动、不编造世界事实），不写具体性格。

## 3. 接口（13 条）

```
角色：GET /api/characters/{id}/ai-role            （不存在时返回预览）
      POST /api/characters/{id}/ai-role/build     （生成并保存）
      PUT /api/characters/{id}/ai-role            （改称呼/语气/态度/开关）
会话：POST /api/chat/threads；GET /api/worlds/{wid}/chat/threads
      GET/PATCH /api/chat/threads/{id}
      POST/DELETE /api/chat/threads/{id}/participants…
消息：GET/POST /api/chat/threads/{id}/messages
记忆：GET /api/chat/threads/{id}/memories；DELETE /api/chat/memories/{id}
```

### 私聊调用链

1. 用户消息先落库（AI 失败也不会丢消息）；
2. 组装 system：世界名 + 角色设定 + 记忆片段 + 行为约束；
3. 取最近 14 条消息作为上下文；
4. 统一 `ai_engine` 客户端（支持访客 Key / 站长 Key / 模型热切换）；
5. 回复落库、更新会话时间、生成一条简短情景记忆（每会话上限 200 条，可删）；
6. 关闭角色开关后拒绝发言（409），会话归档后拒绝发言。

群聊消息接口会明确拒绝（409），防止在调度器未完成时产生无顺序的多人回复。
