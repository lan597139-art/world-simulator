# K1 实施报告：AI 伴侣自我人物

日期：2026-11-11  
结论：**已实现自我人物与聊天身份绑定**；未实现"伴侣角色专属创建向导/多自我人物"。

---

## 1. 数据层

`characters` 新增两列（M024，无新表）：

| 字段 | 说明 |
| --- | --- |
| `persona_type` | `npc`（默认）/ `self` |
| `owner_user_id` | 自我人物归属，当前 `local` |

约束：

- 每个世界最多一个未归档 `self`；
- 普通角色默认 `npc`，旧人物全部回填；
- 自我人物仍走 03 人物档案，不另建表。

## 2. 聊天身份

`ChatThread.settings` 新增 `user_character_id`：

- 必须指向同世界的 `self` 人物；
- 提示词优先读取自我人物的姓名、身份、背景；
- 未绑定/为空时，退回原 `user_identity` 手填身份；
- 旧的"我的身份"输入保留。

## 3. 前端

- 03 人物档案顶部新增「AI 角色 / 自我人物（我）」切换；
- 保存时写入 `persona_type`；
- 人物列表显示"自我人物 · 我"徽章；
- 聊天页"我的身份"新增自我人物下拉（仅列本世界 self）；
- 保存身份同时写 `user_character_id`。

## 4. 实测

- `smoke_self_avatar.py`：**7 项通过**；
- 全量：**386 passed / 0 failed / 14 suites**；
- 迁移演练：24/24，62 表；
- 浏览器构建、tsc 通过（未在浏览器内实际创建自我人物）。

## 5. 未做 / 边界

- 一个世界只能一个自我人物；多用户/多身份需认证就绪后放开；
- 无伴侣专属入口（仍从人物/聊天进入）；
- 未做自我人物的独立成长/日记联动（K2/K3）；
- 未做头像/声音等伴侣化设置。

## 6. 兼容性

- 旧人物无感知；
- 不绑定自我人物的旧会话行为不变；
- 新增列可空/有默认，旧 API 客户端不受影响。
