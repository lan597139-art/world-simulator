# 游戏体验中心页面落地报告

## 范围

延续 B 方案玻璃 Bento，落地「游戏体验中心 / 剧情参与与世界探索」独立全局页面。入口在全局侧栏「创作与体验 / 游戏体验中心」，路由 `?page=game-center`。

未修改产品架构、后端、数据库、API 或数据结构。

## 页面设计

- Hero：真实剧情项目 / 分支 / 已记录结局 / 剧情节点统计与「继续游戏」。
- 剧情游戏：真实故事项目封面、状态、premise、故事空间、结局、选择与角色数。
- 我的进度：最新真实分支、最新节点、节点/结局计数、已记录选择、进度已保存状态。
- 我的游戏：6 个真实分支卡片，按更新时间排序。
- 角色扮演：4 位真实角色样本，选择角色或进入模拟。
- 多人体验：0 房间真实空状态。
- 作品与评价：0 发布 / 0 评价真实空状态。
- 结局图鉴：2 个真实故事结局，终局/开放标签。
- 世界探索：世界简介与四个真实入口。

## 真实数据

截图时本地库：

- 剧情项目 1 个：`凡人修仙传 · 七玄门篇`，状态连载中。
- 故事空间 2 个；故事结局 2 个：`反杀后入黄枫谷`（终局）、`亡命未定`（开放）。
- 选择 1 条，状态 resolved。
- 游戏分支 6 个，共 7 个节点；模拟结局 0 个。
- 当前最新分支：`沙盒演示 · 外援缓冲线`，1 节点、0 结局。
- 游戏世界人物 5 位。

## 实际交互

- 「继续游戏」、剧情游戏「进入游戏」、分支卡、我的进度按钮进入 `?product=game&world=凡人修仙传&page=multipath`。
- 「故事线」进入真实故事线管理；「进入模拟」进入模拟运行。
- 「选择角色」进入人物管理；「结局图鉴」回到真实故事线。
- 「进入世界」进入世界管理；「世界设定」「世界结构」「人物关系」分别进入真实页面。
- 分支状态显示为「进行中」；故事状态显示为「连载中」。
- 多人、发布、评价保持真实空状态，不生成假房间或假评分。

## 边界

- 单用户分支体验，没有多人联机、房间、协作剧情后端。
- 游戏发布与体验评价没有后端，不伪造评分或销量。
- 结局图鉴只展示数据库真实结局，不预生成未解锁内容。
- 未修改后端、数据库、API；无新增表。
