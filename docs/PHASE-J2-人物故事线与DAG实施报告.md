# J2 实施报告：人物故事线与 DAG 关系

日期：2026-11-11  
结论：**已实现人物故事线、事件多线引用与人物线关系边**；未做自动图布局与剧情冲突检测。

---

## 1. 数据层（59 → 62）

| 表 | 作用 |
| --- | --- |
| `story_threads` | 人物线：所属故事/世界、绑定人物、父线、main/side/copy/shadow/ensemble |
| `story_thread_events` | 人物线—事件引用，带顺序、角色、备注；**不复制事件** |
| `story_thread_edges` | 人物线 DAG：impact/converge/fork，可带起点/终点事件 |

M023 仅补索引，无旧表改动。

## 2. 接口（新增 6 类）

```
GET/POST   /api/stories/{id}/threads
PATCH/DELETE /api/story-threads/{id}
POST       /api/story-threads/{id}/events
DELETE     /api/story-thread-events/{id}
GET/POST   /api/stories/{id}/thread-edges
DELETE     /api/story-thread-edges/{id}
```

规则：

- 人物线、事件、绑定人物必须同世界；
- 配角可建 `kind=main` 的独立主线，不强制只做支线；
- 同一事件可被多条人物线引用（共享，不复制）；
- 同一人物线不能重复挂同一事件；
- 删除人物线不删除事件，子线自动上提为根；
- 边禁止自环，两端必须同故事。

## 3. 前端

- 故事线管理页头部新增「人物线」按钮；
- 弹窗内含：创建人物线（名称/类型/人物）、事件挂入/移出、删除；
- 关系区列出 DAG 边，并支持创建影响/汇合/分叉；
- 不改变原故事线空间、结构单元、选择节点页面。

## 5. 未做 / 边界

- 无自动 DAG 布局、无环检测（仅阻止自环）；
- 无"人物线剧情冲突/一致性"检查；
- 未与结构单元自动同步（人物线事件与单元事件是两套挂接）；
- 事件在人物线中的顺序仅 `order_index`，无拖拽排序；
- 官方故事未预置人物线，避免伪造剧情。

## 6. 兼容性

- 新表带 `world_id`，纳入世界快照/级联清理；
- 旧故事线数据不受影响；
- 删除人物线只清理引用和边。

## 7. 文档口径

人物线是**用户可编辑结构**；本次未替官方故事生成任何人物线内容，符合"不编造剧情"约束。
