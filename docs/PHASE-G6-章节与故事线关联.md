# 阶段 G6：章节与故事线关联（已实现）

不改 `stories`（章节表）结构；新增关联表，使章节能归入故事线的空间/单元。

---

## 1. 数据层（55 → 56 表）

`story_chapter_links`：

| 字段 | 说明 |
| --- | --- |
| `story_id` / `space_id` | 归属故事与空间 |
| `unit_id` | 可选，归入某结构单元 |
| `chapter_id` | 唯一：一个章节只能归一个空间 |
| `order_index` | 空间内排序 |

`M019_story_chapters` 只补索引；不进入世界快照，删世界时级联清理。

## 2. 规则

- 章节必须属于同一世界；
- 空间必须属于该故事；
- 单元必须属于该空间；
- 同一章节重复关联 → 移动（upsert），不产生第二份；
- 解除关联只删链接，不删章节正文。

## 3. 接口

```
POST /api/stories/{id}/chapter-links   { chapter_id, space_id, unit_id? }
GET  /api/spaces/{id}/chapters
DELETE /api/story-chapters/{link_id}
```

故事总览的空间行新增 `chapter_count`。

## 4. 页面

- 故事线页右栏新增「关联章节」：选择章节 → 关联到当前空间；列出标题、字数、解除按钮；
- 章节下拉显示字数，便于区分同名的官方草稿（官方世界存在两个同名「推演 · 韩立通过黄枫谷入门测试」）。
- 空间卡片显示「N 章」。

## 5. 实测

- `smoke_storyline.py`：**48 项全通过**（新增 7 项：创建章节、空间/单元关联、列表、计数、一章只归一个空间、跨世界拒绝、解除）。
- 浏览器：官方世界「正史」空间成功关联 997 字章节「推演 · 韩立通过黄枫谷入门测试」并显示字数。
- 全量回归：**343 passed / 0 failed**；`tsc`、`vite build` 通过。

## 6. 边界

- 章节内容仍是原 `stories` 表中的独立文本，不随空间分支隔离；关联只表达"归入哪条线"。
- 不支持一个章节同时挂多个空间（避免叙事歧义）；需要时复制章节后再分别关联。
- 页面暂不支持直接在章节编辑器内选择故事线（关联入口在故事线页）；接口已具备。
