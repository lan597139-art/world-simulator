## 一、侧边栏移动端抽屉化

导航抽屉的 CSS/触发在阶段二之前已有雏形（`navigation.css` 的 `@media (max-width:1024px)` +
`.cc-nav-toggle`），但实测有 4 个真问题，本次全部修掉：

| 问题 | 修复前实测 | 修复后实测 |
|---|---|---|
| 抽屉里点导航后不关闭 | `?page=community` 已加载，抽屉仍 `visible` 且遮罩还在 | 自动收起（`is-drawer-open` 移除、遮罩消失） |
| 背景可滚动 | `body.overflow = visible` | 打开时 `hidden`，关闭后恢复原值 |
| ESC 不关闭 | 无键盘关闭 | ESC 关闭并把焦点还给顶栏开关 |
| 无焦点管理 | 焦点留在原处 | 打开聚焦首个导航项；开关带 `aria-expanded`，抽屉 `role="dialog" aria-modal="true"` |

附带修正：窄屏下不再套用桌面的「折叠偏好」（此前窄屏自动收起会被带到宽屏，导致桌面打开就是收起状态），
回到宽屏会撤销「窄屏自动收起」，用户手动折叠的状态仍保留。

## 二、跨页面移动端信息分层

新增 `src/styles/mobile-layering.css`（在 `main.tsx` 最后引入），分 7 组规则：

1. 触控目标 ≥40px（导航项、主按钮、页签）
2. 标题区压缩：`h1` 降到 22px，说明文字按 2 行截断，装饰性大数字在手机上隐藏
3. 区块间距/内边距收紧
4. 横向条带（`.cw-scene-strip`、页签条）改为换行，内容不再藏在横滑里

> 该层对字号/行高/内边距使用 `!important`：页面样式表由懒加载 chunk 注入，加载顺序晚于本文件，

## 七、资产库详情面板：窄屏关闭机制

覆盖式面板原来只有一个「关闭」小按钮，手机上没有返回手势也没有返回键支持。现在四条路径都成立：

| 路径 | 实测（390×844） |
|---|---|
| Esc 键 | 面板关闭，`body` 滚动锁恢复 `visible` |
| 面板顶部「← 返回列表」 | 关闭 |
| 浏览器返回键/手势 | 关闭，并**停在 `?page=creator-assets`**（不会退出资产库） |
| 点遮罩空白处 | 关闭 |

打开时 `role="dialog" aria-modal="true"`、背景滚动锁定、关闭后焦点回到触发行。

不能用随主题派生的 `--ws-inset-*`——否则深色下表面会下沉。三处深色块已逐档回填修正。

### 14.2 `appearance-studio.css` 的公式与静态色分流

控制台文件里的白/黑分两类，**不能一刀切**：

- **动态公式**（`color-mix(in srgb, #fff calc(var(--ws-g-*) * N%), …)`，透明度由控制台实时计算）
  不能换成带透明度的令牌（会叠加两次 alpha），改为引入**光源原语**做等价替换：
  `--ws-light` / `--ws-light-rgb` / `--ws-dark` / `--ws-dark-rgb` / `--ws-dispersion-a-rgb` / `--ws-dispersion-b-rgb`。
  实测公式目标（`.cc-topbar` 等）明暗两主题、70 个字段**改动前后 0 差异**。
- **静态设计色**映射语义令牌：投影→`--ws-shadow-*`、高光→`--ws-rim-*`、
  浅遮罩→`--ws-scrim-soft`、成功提示→`--success-strong`。

### 14.3 语义调色板（精确取值）

白/黑之外，全站散落的非白/黑语义色（绿/红/琥珀/蓝/紫 + 灰阶）按色族抽取为
`--ws-pal-<族>-<序号>`，**取值与原字面量逐字一致**，视觉零变化，收敛为单一来源。
覆盖 `src/styles/*.css`（除令牌层）与 `src/App.css`，共 20 个文件、166 个令牌；
页面本地令牌（如 `.tlx-page` 的 `--tlx-event`）改为引用调色板。
