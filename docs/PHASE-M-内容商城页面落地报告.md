# 内容商城页面落地报告

## 范围

延续 B 方案玻璃 Bento，落地「内容商城 / 数字资产交易与授权」独立全局页面。入口在全局侧栏「创作与体验 / 内容商城」，路由 `?page=content-store`。

当前数据库没有商品、订单、授权、支付或结算能力，因此本轮落地为**真实可上架资产预览 + 明确交易空状态**，不伪造价格、销量、订单或授权。

未修改产品架构、后端、数据库、API 或数据结构。

## 页面设计

- Hero：0 商品、真实可上架资产、0 订单、0 授权统计与资产预览入口。
- 交易状态带：说明商品、支付、数字交付、订单与结算未接入。
- 搜索筛选：全部 / 世界 / OC / 剧情 / 模板 / 授权 + 结果计数。
- 可上架资产：真实世界、OC、剧情卡片，全部标注「未上架」，不显示价格。
- 商城首页：0 在售商品、空状态与商城目录真实计数。
- 热门创作者：0 公开榜单 + 当前本地创作者。
- 我的订单 / 我的授权：0 真实空状态。
- 创作者销售中心：真实资产数量、0 商品、0 订单、¥0 结算与真实拆分。

## 真实数据

截图时本地库：

- 商品 0；订单 0；授权 0；结算 ¥0。
- 可上架资产 7 项：世界 1（凡人修仙传）、OC 5（韩立、墨居仁、张铁、厉飞雨、南宫婉）、剧情 1（凡人修仙传 · 七玄门篇）。
- 作品 3 篇。
- 模板 0；授权记录 0。
- 当前创作者：本地账号；预览环境未提供显示名时回退为「本地创作者」。

## 实际交互

- 搜索「韩立」返回 5 项资产（世界/OC/剧情简介中包含韩立）。
- 分类筛选「授权」「模板」显示真实空状态，不生成虚拟商品。
- 点击资产「预览资产」：世界进入世界管理、OC 进入人物管理、剧情进入故事线管理。
- 商城目录五类计数与筛选联动。
- 销售中心「作品 3」进入真实写作工作台。
- 订单、授权、购买、支付、上架、下架不提供无效按钮。

## 边界

- 没有商品、SKU、价格、支付、数字交付、订单、授权范围、评价或结算表与接口。
- 因此不展示价格、销量、评分、购买按钮或假订单；资产全部标记「未上架」。
- 单用户空间没有公开创作者、热门榜单或跨用户交易。
- 未修改后端、数据库、API；无新增表。
