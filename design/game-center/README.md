## 页面结构

1. **中心 Hero**：真实剧情项目 / 分支 / 结局 / 节点统计与「继续游戏」。
2. **剧情游戏**：真实故事项目、所属世界、premise、故事空间、结局、选择与角色数。
3. **我的进度**：最新真实分支、最新节点、节点/结局计数、已记录选择与保存状态。
4. **我的游戏**：6 个真实分支，展示状态、节点数、结局数与更新时间。
5. **角色扮演**：真实人物样本，进入人物管理选择角色或进入模拟运行。
6. **多人体验**：0 个多人房间的真实空状态。
7. **作品与评价**：0 个已发布游戏 / 0 条评价的真实空状态。
8. **结局图鉴**：2 个真实故事结局，标注终局/开放结局。
9. **世界探索**：世界简介与进入世界、世界设定、世界结构、人物关系入口。

## 实际可用能力

- **进入游戏 / 继续游戏**：进入现有多路径推演页。
- **剧情对话与分支**：沿用现有故事线、故事空间、选择与多路径分支能力。
- **我的进度**：读取最新真实分支与节点，展示真实选择状态；分支进度由现有能力保存。
- **结局图鉴**：读取真实故事结局；模拟结局存在时一并展示。
- **角色扮演**：进入人物管理或模拟运行。
- **世界探索**：世界管理、世界设定、世界结构、人物关系均进入现有真实页面。
- **世界 / 角色**：真实游戏世界与 5 位角色，不生成虚构 NPC。

## 边界

- 当前是单用户分支体验，没有多人联机、房间或协作剧情后端。
- 游戏作品发布与体验评价没有后端，不伪造评分、下载量或评论。
- 结局图鉴只展示数据库真实记录，不预生成未解锁结局。
- 未修改后端、数据库、API；无新增表。
