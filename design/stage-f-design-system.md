# 阶段 F 全局视觉与设计系统验收记录

## F1 字体系统

- 本地安装并打包两款开源可变字体：
  - Geist Variable（英文、数字、拉丁字符，OFL）
  - Noto Sans SC Variable（中文，OFL）
- 字体入口在 `src/main.tsx` 引入，构建产物按 unicode-range 分片，不依赖运行时 CDN。
- 全局字体 Token：`--font-sans`、`--font-serif`、`--font-mono`。
- 层级 Token：`--text-xs/sm/base/lg/xl/2xl/3xl`、`--leading-*`、`--weight-*`、`--tracking-*`。
- 标题、正文、辅助说明、按钮、输入框、数据标签使用统一字号/字重/行高。
- 阅读型正文使用 `--font-serif`（宋体回退），数据与编号统一 tabular-nums。

## F2 苹果式黑白主题

- 浅色：`#f5f5f7` 主背景、白色卡片、`#1d1d1f` 主文字、`#5f5f66` 辅助文字。
- 深色：`#0e0e10` 主背景、`#1c1c1e` 卡片、`#f2f2f4` 主文字、`#a1a1a6` 辅助文字。
- 主按钮使用黑白反转，不铺满高饱和强调色。
- 保留“跟随系统 / 浅色 / 深色”设置，显式主题覆盖系统偏好。
- 浅色与深色分别定义输入框、边框、焦点环与危险色。

## F3 对比度与可读性

- 主文字/主背景对比度：浅色 15.46:1，深色 17.25:1。
- 辅助文字/卡片对比度：浅色 8.11:1，深色 8.16:1。
- 均高于 WCAG 2.2 AA 的 4.5:1 正文基线。
- 输入框占位符使用明确的 `--text-muted` 混色，不再淡到不可读。
- 卡片、表格、分隔线保留 1px 可辨识边界，不只依赖模糊。

## F4 Liquid Glass

- 玻璃默认模糊从 40px 降到 28px、饱和度 145%、透明度 92%。
- 文字卡片使用稳定的 `--card-bg`，并在全局设计系统中覆盖关键卡片容器。
- 玻璃效果保留空间感；重要信息不依赖透明层叠。
- 支持 `prefers-reduced-motion` 与设置中的减少动效。

## F5 设计 Token

新增 `src/styles/design-system.css`，统一：

- 字体家族与字号层级
- 文字、背景、卡片、边框、分隔线
- 圆角、焦点环、输入框、滚动条
- 浅色/深色映射
- 密度、字号、减少动效
- 链接、选中文本、禁用态、表格与正文阅读

所有全局壳页面（创作中心、作品、灵果、社区、设置、写作、漫画工作台）统一继承；页面局部不再新增全局字体定义。

## 验证

- `tsc --noEmit`、`vite build` 通过。
- 浏览器实测字体加载：中文 `Noto Sans SC Variable` 与英文 `Geist Variable` 均 `document.fonts.check` 为真。
- 浅色/深色对比度计算结果见上。
- 390px 下创作中心、作品、灵果资源、设置中心均无横向溢出。
