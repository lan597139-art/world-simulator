## 页面结构

1. **中心 Hero**：标题、说明、真实角色 / 会话 / 记忆 / 关系统计与「开始对话」。
2. **推荐角色**：从真实人物库按主角、重要配角、AI 伴侣排序，展示 3 位。
3. **AI 伴侣**：真实伴侣角色小满、独立会话数、记忆数、AI 人格数，以及人格中心与云宝入口。
4. **最近会话**：真实聊天线程，展示参与角色、最后消息、消息数与日期，点击进入聊天页。
5. **多人聊天室**：真实群聊线程、参与角色与消息数。
6. **我的角色**：6 位真实角色的完整名册，支持搜索与分类筛选。
7. **关系互动**：真实关系记录总数、互动事件总数与 3 条人物关系样本。
8. **记忆管理**：真实长期记忆总数与 3 条记忆样本。
9. **角色与玩法**：角色扮演入口、创建角色入口、角色发布与授权边界说明。

顶部提供真实搜索与分类筛选：全部 / 主角 / 重要配角 / 配角 / 反派 / AI 伴侣。

## 实际可用能力

- **角色筛选**：客户端按角色定位过滤；搜索覆盖姓名、身份、简介、角色与世界名。
- **单角色对话**：点击角色卡、名册或「开始对话」进入真实聊天页，并自动选择该角色所属产品与世界。
- **多人聊天室**：读取真实群聊线程，点击进入现有聊天室。
- **AI 伴侣**：展示小满的真实会话与记忆；可进入 AI 人格中心、管理记忆、打开云宝。
- **关系与事件**：关系网络、互动事件均进入现有真实页面。
- **记忆管理**：展示真实长期记忆；入口进入现有记忆管理页。
- **角色扮演**：进入模拟运行；创建角色进入真实人物管理。
- **发布与授权**：明确显示 0 个公开角色 / 0 项授权，不提供假发布或假授权按钮。

## 边界

- 单用户本地空间，没有公开角色广场、关注或跨用户授权。
- 角色发布、公开授权、使用范围与收益没有后端，本轮不生成假状态，也不放置无效提交按钮。
- 会话列表只展示真实线程；没有消息的空线程不进入「最近会话」。
- 角色、消息与记忆正文保留原始语言，不伪造翻译。
- 未修改后端、数据库、API；无新增表。
