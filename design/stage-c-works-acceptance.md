# 阶段 C · 创作中心与作品管理验收

## 交付范围

四场景共享一套作品元数据，但不复制世界、人物、故事内容：

- `game` 游戏创作
- `literature` 文学创作
- `companion` 虚拟角色创造与体验
- `diary` 日记与传记

作品保存名称、简介、封面、分类、状态、作者、时间、世界引用、人物引用和扩展 `settings`；正文、世界树、人物设定、事件与故事线仍留在原有产品工作台。

## 后端

- 新表 `creative_works`（M052，兼容 SQLite 旧库与 PostgreSQL 新库）。
- `/api/creative-works` CRUD 与 `/api/creative-works/summary`。
- 所有权隔离：列表、详情、修改、删除均按当前用户（`owner_user_id`）隔离。
- 场景合法值：`game / literature / companion / diary`。
- 状态合法值：`draft / in_progress / completed / archived`。
- 分类按场景校验，跨场景分类返回 422。
- `world_ids` 逐项校验访问权限；`character_ids` 校验存在性及其所属世界访问权限。
- 作品创建后场景不可切换，避免分类与历史内容错位；编辑名称、简介、分类、状态、封面和引用关系。
- 封面与人物图片复用 `/api/creator-assets/upload`，文件持久化到 uploads/S3，并登记为创作者媒体资产。

## 前端

### 统一作品管理

- 新页面 `我的作品`，可从左侧“创作管理”和 URL `?page=works` 进入；不依赖当前世界。
- 场景筛选、状态筛选、关键词搜索、场景数量统计。
- 新建作品弹窗：名称、简介、场景、场景分类、状态、封面、关联世界、引用人物。
- 编辑作品资料；进入对应创作空间；查看/管理世界与人物引用；删除作品（不删除世界和人物）。
- 作品详情提供 `故事线` / `写作` 入口，将作品世界引用接入现有叙事系统。
- 封面在创作中心、作品列表、作品详情、用户中心作品中展示。
- 作品页兼容桌面与移动端；移动端弹窗表单单列、选项单列。

### 人物图片

- 人物基础档案顶部新增“人物形象”：
  - 头像上传/替换/移除，写入 `basic_profile.avatar`。
  - 多张立绘上传，写入 `basic_profile.portraits[]`。
  - 立绘大图预览与左右切换；单张可移除。
- 人物列表使用头像作为识别图；人物编辑页显示头像与当前立绘。
- 图片保存相对 `/uploads/...` 路径，展示时经 `resolveMediaUrl` 解析，兼容生产 API 域名。
- 上传文件同时登记为 `image` 媒体资产，标题区分“作品封面 / 人物头像 / 人物立绘”。

### 创作中心与用户中心

- 创作中心“我的作品”数量改为统一作品统计。
- 新增“最近作品”条，展示封面、分类和状态，点击进入作品管理。
- 用户中心作品展示与数量改为统一作品，封面和创作状态同步。

## 本地验证

- 后端：`713 passed across 26 suites`；迁移演练 `52 / 52`，重复执行无新增。

- 浏览器流：
  - 从创作中心“我的作品”进入 `?page=works`，面包屑和侧栏激活正确。

  - 封面真实上传、预览、替换后详情显示；重载后仍存在。

  - 390px 视口作品页无横向溢出，创建弹窗和保存按钮可用。
  - 创作中心最近作品与用户中心作品封面正常加载。
