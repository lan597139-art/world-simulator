## 页面结构

1. **中心 Hero**：0 商品 / 真实可上架资产 / 0 订单 / 0 授权统计与资产预览入口。
2. **交易状态带**：明确说明商品、支付、数字交付、订单与结算尚未接入。
3. **搜索与分类**：全部 / 世界 / OC / 剧情 / 模板 / 授权，覆盖真实资产预览。
4. **可上架资产**：1 个世界、5 位 OC、1 个剧情，全部标记「未上架」，不显示价格。
5. **商城首页**：0 个在售商品、真实空状态与商城目录计数。
6. **热门创作者**：0 个公开创作者榜单；展示当前本地创作者，不生成排名。
7. **我的订单**：0 条记录。
8. **我的授权**：0 项授权资产。
9. **创作者销售中心**：真实资产数量、0 在售商品、0 成交订单、¥0 结算与真实资产拆分。

## 实际可用能力

- **资产搜索与筛选**：客户端检索真实世界、OC 与剧情的标题和简介；模板、授权为空分类。
- **资产预览**：世界进入世界管理，OC 进入人物管理，剧情进入故事线管理。
- **商城目录**：五个分类显示真实计数，可直接切换筛选。
- **创作者销售中心**：汇总真实可上架资产与作品数量；订单、销售与结算保持 0。
- **语言与导航**：保留全局侧栏、顶栏面包屑、云宝与语言切换。

## 边界

- 当前没有商品、SKU、价格、支付、数字交付、订单、授权范围、评价或结算表与接口。
- 因此页面不展示价格、销量、评分、购买按钮或假订单；所有资产标记「未上架」。
- 单用户空间没有公开创作者、热门榜单或跨用户交易。
- 未修改后端、数据库、API；无新增表。
