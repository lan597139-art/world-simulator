# 阶段 F 视觉系统落地（第一批）

对应《视觉设计.md》的 P0/P1：文字可读性、语义 Token、材质分工、背景自适应，以及高频路径国际化。

## 已完成

### 1. 语义化文字颜色

不再由页面自行猜灰色层级，统一为：

| Token | 浅色 | 深色 |
|---|---|---|
| `--text-main` | `#1d1d1f` | `#f4f4f6` |
| `--text-muted` | `#4b4b52` | `#bbbbc2` |
| `--text-faint` | `#62626a` | `#9a9aa2` |
| `--text-disabled` | `#7a7a82` | `#8a8a92` |

深色模式次要文字从旧 `#a1a1a6` 提升到 `#bbbbc2`，浅色模式次要文字从 `#5f5f66` 加深到 `#4b4b52`。普通文字按 WCAG AA 4.5:1 目标处理。

同时增加状态色 Token：

- `--success-strong`
- `--warning-strong`
- `--danger-strong`
- `--info-strong`
- `--purple-strong`

原有页面中的深绿、砖红、土黄、紫色硬编码文字改为语义 Token，避免浅色/深色只适配一边。

### 2. 玻璃材质分工

明确两类：

**毛玻璃 / Frosted Glass**

- 导航栏、侧边栏、普通信息卡、工具栏、弹窗背景
- 使用 `.glass-frost` / 默认 `.glass-card`
- 稳定着色、低折射、轻边框，不依赖彩虹高光
- 侧边栏单独使用反色 `--sidebar-bg`，不会出现浅色主题白底白字

**液态玻璃 / Liquid Glass**

- 首页创作场景卡（已有 `LiquidGlass` WebGL）
- 登录入口等重点视觉
- 使用 `.glass-liquid`
- 更高模糊、边缘高光、克制辉光
- 普通卡片不再默认使用液态效果

**稳定底色**

- 阅读正文、Markdown、表格、复杂数据账本
- 强制关闭 `backdrop-filter`，使用 `--surface-solid`

设置中心新增材质说明，明确“毛玻璃用于常规容器，液态玻璃只用于重点入口”。

### 3. 背景图自适应

`applyAppearance()` 会读取背景图并采样 32×32 像素，判断：

- `vivid`：高饱和
- `detail`：高细节
- `dark`：暗色
- `light`：高亮
- `mid`：普通

根据结果设置：

- `--glass-readability-floor`：玻璃不透明度的可读性下限
- `#app-background::after` 的遮罩强度
- `data-bg-tone`

用户仍可手动调玻璃透明度，但不会低于当前背景类型的安全下限。背景加载失败或 canvas 跨域无法采样时，使用保守的 `detail` 档。

### 4. 高频路径国际化

已完成英文覆盖：

- 全局侧栏、产品名、产品简介
- 创作中心首页
- 工作区顶部导航（`ProductWorkspaceNav`）
- 世界管理页（`WorldsPage`）
- 我的作品页分类与筛选
- 灵果中心灵植名称、简介、单位
- 设置页、身份中心原有英文路径复核

用户创作的名称、简介、社区正文、角色内容不翻译。

### 5. 官方背景库

新增 6 个内置场景，放在 `public/backgrounds/`，无外部图片版权依赖：

- 雾林
- 暮色海岸
- 极光夜
- 沙丘
- 水墨山峦
- 霓虹城市

设置 → 体验 → 官方背景库可直接点击应用；缩略图、选中描边、中英文名称同步显示。内置背景走前端静态资源，不会误拼到后端域名。

### 6. 视觉可见性加强

- 默认环境光增强（浅色/深色都更明显），让毛玻璃有可折射的背景层次
- 全局侧栏与旧工作区侧栏的当前模块增加左侧高光条和内描边
- 设置页新增“毛玻璃 / 液态玻璃”实物示例，不再只靠文字说明
- 官方背景选中后有明确描边和高亮

### 8. 专业模块材质统一

以下页面不再各自使用 90% / 92% / 实色卡片，而是统一为同一套专业工作区材质：

- 世界管理
- 世界建设配置
- 人物管理
- AI 角色对话
- 世界结构
- 世界设定
- 关系与组织
- 事件管理
- 时间线
- 模拟与写作
- 故事线管理

统一参数：

- 背景：`--workspace-glass-alpha` 默认 76%
- 模糊：`blur(22px) saturate(140%)`
- 描边：同一 `--glass-border`
- 阴影：同一内高光与外阴影
- 自定义高细节背景时自动提高到 84%–90%，保证文字
- 页面底色必须透明，玻璃叠在实色底上会被误判成白卡
- 关系与组织 3D 宇宙、时间线、模拟、故事线画布也纳入同一材质
- 故事线根节点恢复深色底浅色字，不再被统一材质染白

实现方式：

- 通用 `.ws-glass-surface`
- 修改 `.glass-card` 统一材质
- 时间线 `.tlx-page / .tlx-head / .tlx-controls / .tlx-item`
- 模拟 `.sim-panel / .sim-console`
- 故事线 `.slx-canvas-wrap / .slx-node`
- 聊天、世界结构、世界设定、关系页的主要面板加统一类

### 7. 移动端顶栏

390px 下隐藏搜索框和后端状态条，压缩 AI 入口，保留返回、提醒、个人菜单；修复顶栏内容被挤出屏幕的问题。

## 人工检查建议

1. **浅色 / 深色文字**
   - 设置 → 外观，切换浅色、深色、跟随系统
   - 检查侧栏、工作区顶部、设置说明、作品分类、灵果流水
   - 深色模式下不应出现灰到看不清的说明文字

2. **材质分工**
   - 创作中心首页：场景卡是液态玻璃，工具卡是毛玻璃
   - 普通世界卡、设置卡、侧栏是毛玻璃
   - 阅读页正文和表格应为稳定底色，不随背景扭曲

3. **官方背景**
   - 设置 → 体验 → 官方背景库
   - 依次点击 6 个缩略图，背景应立即切换，选中项有描边
   - 刷新后仍保留；清除按钮可恢复纯色环境

4. **专业模块材质统一**
   - 依次打开世界管理、世界建设配置、人物管理、AI 角色对话、世界结构、世界设定、关系与组织、事件管理、时间线、模拟与写作、故事线管理
   - 主要卡片应为同一档半透明毛玻璃，不再出现纯白实色块
   - 浏览器检查 `backdrop-filter` 应统一为 `blur(22px) saturate(140%)`

5. **背景自适应**
   - 上传一张高饱和或高细节图片
   - 把背景透明度拉到 100%，玻璃透明度拉到最低
   - 卡片文字仍应清晰；背景上应有一层轻微遮罩
   - 恢复默认背景后，`data-bg-tone` 应消失

6. **英文**
   - 切 EN 后检查：创作中心、世界管理、我的作品、灵果中心、设置、身份中心
   - 中文用户名、作品标题、社区正文保持原文

7. **移动端**
   - 390px 宽度检查创作中心顶栏
   - 页面不应横向滚动，个人菜单仍可打开

## 本版边界

- 全站国际化尚未完成：角色建设、世界建设、写作、社区管理等深层编辑器仍有硬编码中文，需按页面继续迁移。
- 状态色替换覆盖的是 CSS 文字颜色；页面内少量内联 `color: '#...'` 仍需逐页清理。
- 背景分类目前是亮度/饱和度/方差启发式，不含人脸、建筑等语义识别。
- 官方照片库、照片授权、收藏与跨场景复用尚未实现；当前内置的是 6 张无版权 SVG 场景，不是照片库。
- 液态玻璃的色散参数继续沿用现有 WebGL 组件，本批只收敛使用范围，不重写 shader。
