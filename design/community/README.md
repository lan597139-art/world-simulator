## 页面结构

1. **社区推荐**：从当前真实作品库按字数选择 1 篇主推荐，另列 2 篇作品。
2. **世界专区**：真实世界、世界类型、简介、核心设定、人物数与剧情数。
3. **OC 专区**：6 位真实人物，显示姓名、身份、简介。
4. **剧情专区**：真实故事项目、状态与所属世界。
5. **创作动态**：真实作品最近更新时间，可打开阅读。
6. **关注动态**：0 关注 / 0 粉丝，单用户空状态。
7. **热门榜单**：作品/角色/世界三列占位，等待真实互动数据，不伪造排名。
8. **创作者专区**：当前本地创作者、创作身份、真实作品与身份中心入口。
9. **共创专区**：0 个开放项目，空状态。

顶部提供真实搜索与分类筛选：全部 / 作品 / 世界 / OC / 剧情。

## 实际可用能力

- **搜索与分类**：客户端检索作品正文、标题、世界简介/设定、OC 身份/简介、剧情 premise。
- **阅读**：作品弹层直接展示 `plain_text` 正文、字数、状态、创作方式与最近更新。
- **分享**：复制社区链接；剪贴板受限时显示可手动复制的链接面板。
- **发布作品**：打开真实发布面板，调用现有 `POST /api/writings` 写入当前创作库；支持发布或存草稿，成功后立即刷新推荐、创作动态与计数。阅读器中的“在写作页打开”仍进入完整写作工作台。
- **世界 / OC / 剧情入口**：分别进入世界管理、人物管理、故事线管理。
- **创作者身份中心**：进入已落地的 `?page=user-center`。

## 边界

- 当前是单用户本地空间，内容来自本人创作库，没有其他创作者、帖子或公开内容流。
- 点赞、评论、收藏、关注创作者、参与共创没有对应后端，本轮不伪造计数、不放置无效操作按钮。
- 热门榜单没有热度数据，显示等待状态。
- 作品“版本”没有版本表；只展示真实状态、创作方式与最近更新时间。
- 未修改后端、数据库、API；无新增表。
