## 页面结构

- 个人资料：头像首字、昵称、账号、加入时间、简介、个人背景、世界/人物/作品计数。
- 创作者主页：创作身份、3 篇真实作品、4 项创作成就、查看全部作品。
- 我的关注：关注/粉丝 0，单用户本地空间空状态。
- 我的资产库：世界 1、OC 6、剧情 1、模板 0、作品 3，均来自当前本地库。
- 我的收藏：作品/角色/世界 0，空状态。
- 账户管理：账号安全、登录方式、隐私设置、当前身份、退出登录。
- 会员中心：普通用户、未开通、权益与有效期空状态。
- 消费记录：充值 / 购买 / 订单均为 0，空状态。
- 收益账户：¥0.00、交易明细 0、提现记录 0，空状态。

## 实际可用能力

- 编辑昵称：调用现有 `PATCH /api/users/me`，同步顶栏与页面。
- 编辑创作身份、简介、个人背景：保存在浏览器本机 `ws.user.profile.v1.<user_id>`，弹层内明确说明暂存本机。
- 资产行进入对应真实页面；OC 与剧情在未选世界时自动进入首个真实世界，避免被路由守卫打回。
- 退出登录调用现有登出逻辑。

## 边界

- 未修改后端、数据库、API。
- 关注、收藏、会员、消费、收益没有对应数据表与接口，本轮只做完整页面模块和真实空状态，不生成假订单或假收益，不放置无效操作按钮。
- 头像使用昵称首字生成，没有上传接口。
- 账户安全、隐私设置为当前本地单用户模式的只读状态，不提供密码修改。
- 顶部搜索、提醒铃铛沿用创作中心全局顶栏，不新增全局检索或通知后端。
- 模板暂无数据与模板库接口，展示 0。
